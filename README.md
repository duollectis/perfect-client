# Perfect Client

Official source code release of Perfect Client CPVP edition.

> Note: This is an archived version of Perfect Client and is no longer maintained or supported.

## Compatibility
- Minecraft 1.21.8
- Fabric Loader 0.16.0 or newer 
- Java 21

## Dependencies
- Fabric API
- Sodium

## Installation
1) Install Fabric Loader for Minecraft 1.21.8.
2) Install the required dependencies.
3) Download the Perfect Client build from [Releases](../../releases). 
4) Place the .jar file and required dependencies into your Minecraft mods folder.
